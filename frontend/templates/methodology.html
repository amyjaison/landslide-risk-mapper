Machine Learning & GIS Methodology

The Landslide Risk Mapper combines geospatial environmental analysis with a Random Forest machine-learning model to provide a screening-level assessment of landslide susceptibility.

1. Overall System Workflow

The system follows a multi-stage workflow that transforms geographic coordinates into environmental indicators and finally into a machine-learning-based susceptibility score.

Location Input → GIS Data Retrieval → Terrain & Environmental Analysis → Feature Preparation → Random Forest Prediction → Risk Score → GIS Visualization

The platform also displays rainfall, terrain, elevation, historical landslide information and other environmental indicators as supporting context.

2. Geospatial Data Processing

When a user selects a geographic location, the backend retrieves environmental information associated with that location. The system uses elevation and terrain information to calculate local slope characteristics.

  • Latitude and Longitude: Define the target geographic location.
  • Elevation: Represents the terrain height above sea level.
  • Slope: Represents the steepness of the terrain.
  • Rainfall: Provides recent precipitation information for environmental context.
  • Historical Landslides: Provide regional evidence of previously recorded landslide events.

3. Slope Analysis

Slope is one of the primary physical indicators associated with landslide susceptibility. Steeper terrain generally experiences greater gravitational stress and can therefore have increased susceptibility to slope failure.

The GIS engine derives terrain gradients from elevation information using spatial differences between neighboring elevation cells.

dz/dx = [Z(x+1,y) - Z(x-1,y)] / (2 × Δx) dz/dy = [Z(x,y+1) - Z(x,y-1)] / (2 × Δy) Slope = arctan(√((dz/dx)² + (dz/dy)²))
Slope Angle Classification Interpretation
0° – 15° Low Relatively gentle terrain.
15° – 30° Moderate Increased susceptibility under adverse environmental conditions.
30° – 45° High Steep terrain with increased gravitational loading.
> 45° Very High Very steep terrain requiring increased monitoring.

4. Rainfall & Environmental Analysis

Rainfall is an important supporting environmental indicator because prolonged or intense precipitation can increase soil moisture and pore-water pressure.

  • 72-hour antecedent rainfall: Represents recent accumulated precipitation.
  • 24-hour rainfall: Represents short-term rainfall loading.
  • 7-day precipitation: Provides a visual representation of recent rainfall trends through the dashboard hyetograph.

These rainfall indicators are displayed alongside the machine-learning prediction to provide environmental context.

5. Random Forest Machine Learning Model

🌲 Random Forest Landslide Susceptibility Assessment

The primary machine-learning component of the current system is a Random Forest classifier. The model was trained using a public geo-environmental landslide dataset.

The trained model predicts the probability that a location belongs to the landslide-susceptible class. This probability is converted into a score from 0 to 100.

Feature 1 — Slope Local slope angle in degrees.
Feature 2 — Elevation Local terrain elevation in metres.
Target Variable Binary landslide susceptibility class.
Algorithm Random Forest Classifier.

6. Training Dataset

The model was trained using the A Geo-Environmental Feature Dataset for Landslide Susceptibility Modelling in Himachal Pradesh, India from Mendeley Data.

Dataset: Landslide Modelling Dataset

Total samples: 12,409

Training samples: 9,927

Testing samples: 2,482

Predictive features: slope_deg, elevation_m

Target: class

7. Model Training Process

The dataset was divided into training and testing subsets using an 80/20 stratified split. A preprocessing pipeline was then applied before training the Random Forest model.

Dataset → Train/Test Split → Missing Value Imputation → Feature Scaling → Random Forest Training → Testing → Performance Evaluation

The Random Forest configuration uses multiple decision trees and class balancing to improve classification performance across the two target classes.

8. Model Performance

The trained model was evaluated using standard classification metrics on the held-out testing dataset.

Accuracy 75.99%
Precision 74.25%
Recall 83.23%
F1 Score 78.48%
ROC-AUC 83.05%

9. ML Risk Score Calculation

The Random Forest produces a probability for the landslide-susceptible class. The dashboard converts this probability into a percentage-style risk score.

ML Probability = P(Landslide Susceptible | Slope, Elevation) ML Risk Score = ML Probability × 100

The resulting score is classified into four dashboard categories.

Score Risk Level Indicator
0 – 25 Low Risk Green
26 – 50 Moderate Risk Yellow
51 – 75 High Risk Orange
76 – 100 Very High Risk Red

10. GIS Visualization

The predicted susceptibility is presented through an interactive Leaflet map. The dashboard allows users to inspect the selected location together with environmental layers.

  • Topographic basemap
  • Satellite imagery
  • OpenStreetMap basemap
  • Slope analysis layer
  • Rainfall information layer
  • Terrain and elevation layer
  • Historical landslide layer
  • Combined vulnerability visualization

11. Supporting Historical Evidence

Historical landslide records from the NASA Global Landslide Catalog are used as supporting regional evidence. These records help users understand whether landslide events have previously been documented around an area.

Historical observations are presented separately from the Random Forest prediction and should not be interpreted as direct ML input unless explicitly included in the trained model.

12. Limitations & Responsible Use

Important: The Landslide Risk Mapper provides a screening-level susceptibility assessment. It is not a precise prediction of the exact location, timing, magnitude, or occurrence of a future landslide.

The system does not replace detailed geotechnical investigations, field surveys, sensor networks, engineering assessments, or official warnings from relevant authorities.
