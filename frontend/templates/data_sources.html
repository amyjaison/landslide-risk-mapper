Geospatial & Environmental Data Sources

The Landslide Risk Mapper aggregates authoritative open-access geospatial datasets, combining real-time API integrations with robust local caching and validated fallback datasets.

1. Shuttle Radar Topography Mission (SRTM) & ALOS DEM Live API + GeoTIFF Cache

Usage: Elevation grids, topographic relief, and mathematical slope calculations via 2D finite difference gradients. GeoTIFF rasters are generated and saved dynamically using rasterio.

Provider: NASA Jet Propulsion Laboratory (JPL) / USGS / Copernicus 30m Global DEM queried through the Open-Meteo High-Resolution Elevation Service.

2. Open-Meteo & CHIRPS Precipitation Reanalysis Live Satellite Reanalysis

Usage: 72-hour antecedent precipitation, 24-hour peak rainfall, and 7-day cumulative hyetograph monitoring to determine pore-water pressure triggers.

Provider: Climate Hazards Group InfraRed Precipitation with Station data (CHIRPS), ECMWF ERA5, and national weather radar models.

3. NASA Global Landslide Catalog (GLC) Authoritative Historical Records

Usage: Ground-truthing spatial vulnerability with documented historical landslide records, casualty numbers, and reported rainfall triggers.

Provider: NASA Goddard Space Flight Center (GSFC) Open Data, augmented by Geological Survey of India (GSI) and USGS field reports.

4. OpenStreetMap & OpenTopoMap Basemaps Cartographic Basemaps

Usage: High-resolution topographical contours, shaded hillshades, satellite imagery, and geocoded location search powered by the Nominatim reverse geocoder.

Offline Demonstration Fallback Engine

In accordance with hackathon presentation standards, the application implements a gracefully degraded offline demonstration engine. If external network requests encounter timeouts or API quotas, the system transparently utilizes calibrated regional geospatial benchmarks (e.g., Western Ghats monsoon profiles and Garhwal Himalayan topography) without interrupting user interactions.
